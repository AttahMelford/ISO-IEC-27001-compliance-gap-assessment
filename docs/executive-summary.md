# Executive Summary

## 1. Overview

This project presents a simulated ISO 27001:2022 compliance gap assessment for Meridian Digital Services, a fictional software and IT services company.

The assessment evaluates selected Annex A controls to identify potential implementation gaps, evidence deficiencies, and opportunities to improve information security practices.

## 2. Assessment Objectives

- Evaluate selected security controls.
- Document control applicability through a Statement of Applicability (SoA).
- Identify potential compliance gaps.
- Track supporting evidence.
- Map selected controls to NIST CSF 2.0.
- Recommend remediation actions.

## 3. Key Deliverables

- ISO 27001:2022 gap assessment
- Statement of Applicability (SoA)
- Evidence tracking matrix
- NIST CSF 2.0 mapping
- Remediation plan

## 4. Recommendations

The organization should prioritize evidence-based control assessment, documented control ownership, consistent evidence retention, and timely remediation of identified gaps.

## 5. Assessment Limitations

This is a simulated portfolio project based on a fictional organization. Final findings, control statuses, and recommendations will be documented after the assessment work is completed.

This project does not represent an actual certification audit or demonstrate ISO 27001 certification.
