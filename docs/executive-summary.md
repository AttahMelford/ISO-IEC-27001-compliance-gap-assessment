
# Executive Summary

## 1. Overview

This project presents a simulated ISO/IEC 27001:2022 compliance gap assessment for Meridian Digital Services, a fictional software and IT services company.

The assessment reviews 30 selected Annex A controls to identify potential implementation gaps, evidence deficiencies, and opportunities to improve information security practices.

## 2. Assessment Objectives

- Evaluate selected information security controls.
- Document control applicability and implementation status through a Statement of Applicability (SoA) excerpt.
- Identify potential compliance gaps and associated risks.
- Track requested supporting evidence.
- Map selected ISO 27001 controls to NIST Cybersecurity Framework (CSF) 2.0 categories.
- Recommend remediation actions and proposed timelines.

## 3. Key Findings

Most assessed controls are classified as Partially Implemented. Three controls—A.7.4 Physical security monitoring, A.8.13 Information backup, and A.8.24 Use of cryptography—are classified as Not Verified because the available information is insufficient to verify implementation.

These results are simulated assessment findings. Evidence requests and validation activities remain outstanding.

## 4. Key Deliverables

- ISO 27001:2022 gap assessment
- Selected-control Statement of Applicability (SoA) excerpt
- Evidence tracking matrix
- NIST CSF 2.0 mapping
- Remediation plan
- Assessment findings report

## 5. Recommendations

The organization should prioritize evidence-based control assessment, documented control ownership, consistent evidence retention, and timely remediation of identified gaps. High-risk findings should receive appropriate management attention, with progress tracked against agreed remediation timelines.

## 6. Assessment Limitations

This is a simulated portfolio project based on a fictional organization. The assessment findings, control statuses, and recommendations are illustrative and have not been validated through a real organizational audit.

The project covers 30 selected Annex A controls and does not constitute a complete assessment of every Annex A control. It does not represent an actual certification audit or demonstrate ISO 27001 certification.

Evidence validation and final cross-document quality review remain outstanding.
