# Assessment Scope

This document defines the scope of the simulated ISO 27001:2022 compliance gap assessment.

# Assessment Scope

## 1. Purpose

The purpose of this project is to conduct a simulated ISO 27001:2022 compliance gap assessment to identify potential information security control gaps and recommend improvements.

## 2. Organization Profile

- Organization: Meridian Digital Services
- Industry: Software and IT Services
- Location: United States
- Employees: Approximately 150
- Environment: Microsoft 365, cloud-hosted applications, employee laptops, and third-party service providers.

Note: Meridian Digital Services is a fictional organization created for this portfolio project.

## 3. Assessment Scope

The assessment will evaluate 30 selected ISO 27001:2022 Annex A controls across the following areas:

- Organizational controls
- People controls
- Physical controls
- Technological controls

## 4. Assessment Objectives

- Evaluate the implementation status of selected security controls.
- Identify potential compliance gaps.
- Document control applicability in a Statement of Applicability (SoA).
- Identify supporting evidence and evidence deficiencies.
- Map selected controls to NIST CSF 2.0.
- Recommend corrective actions and track remediation.

## 5. Assessment Approach

The assessment will use a simulated review of organizational policies, procedures, records, and other hypothetical evidence.

Each selected control will be assigned an implementation status based on the scenario and available evidence.

Potential gaps will be documented with recommendations and proposed remediation priorities.

## 6. Limitations

This is a simulated portfolio assessment based on a fictional organization. It is not an independent audit, an official certification assessment, or evidence of ISO 27001 certification.
