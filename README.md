# ISO 27001:2022 Compliance & Gap Assessment

## Project Overview

This project demonstrates a simulated ISO 27001:2022 compliance gap assessment for a fictional organization.

The assessment evaluates selected Annex A controls, identifies potential compliance gaps, documents control applicability through a Statement of Applicability (SoA), and tracks supporting evidence and remediation actions.

## Objectives

- Assess 30 selected ISO 27001:2022 Annex A controls.
- Identify and document potential compliance gaps.
- Develop a Statement of Applicability (SoA).
- Create an evidence tracking matrix.
- Map selected ISO controls to NIST CSF 2.0.
- Develop a remediation plan with recommended corrective actions.

## Tools and Frameworks

- ISO/IEC 27001:2022
- NIST Cybersecurity Framework (CSF) 2.0
- Microsoft Excel
- GitHub
