# ISO 27001:2022 Compliance Gap Assessment

A simulated Governance, Risk, and Compliance (GRC) portfolio project assessing 30 selected ISO/IEC 27001:2022 Annex A controls for a fictional organization.

## Project Overview

**Organization:** Meridian Digital Services  
**Industry:** Software and IT Services  
**Framework:** ISO/IEC 27001:2022  
**Cross-Framework Mapping:** NIST Cybersecurity Framework (CSF) 2.0  
**Project Type:** Simulated compliance gap assessment

This project demonstrates a structured approach to assessing information security controls, documenting gaps, tracking evidence requests, evaluating control applicability, and recommending remediation activities.

All findings and evidence descriptions are simulated for educational and portfolio purposes.

## Project Objectives

- Assess selected Annex A controls across organizational, people, physical, and technological categories.
- Document control implementation status and identified gaps.
- Develop a Statement of Applicability (SoA).
- Track evidence requests and outstanding validation activities.
- Map selected ISO 27001 controls to relevant NIST CSF 2.0 outcomes.
- Recommend corrective actions with suggested owners and target timelines.
- Communicate findings in a report suitable for management review.

## Tools and Frameworks

- **ISO/IEC 27001:2022** — information security management system standard.
- **NIST CSF 2.0** — cybersecurity risk management framework used for preliminary cross-framework mapping.
- **CSV files** — structured assessment, applicability, evidence, and mapping records.
- **Markdown** — project documentation and reporting.
- **GitHub** — version control and documentation management.

## Assessment Statuses

- **Implemented:** Evidence supports implementation.
- **Partially Implemented:** Some activities exist, but gaps remain.
- **Not Implemented:** The control has not been implemented.
- **Not Verified:** Available evidence is insufficient to determine implementation status.

## Key Deliverables

1. A structured assessment of 30 selected ISO 27001 Annex A controls.
2. A Statement of Applicability with applicability justifications.
3. An evidence tracking matrix for outstanding evidence and validation.
4. A preliminary NIST CSF 2.0 cross-framework mapping.
5. A remediation plan with suggested owners and target timelines.
6. A findings report documenting observations and recommendations.

## Important Limitations

This is a simulated portfolio exercise based on a fictional organization. It is not a real audit, a verified assessment of an operating company, or evidence of ISO 27001 certification. The control selection and NIST mappings should be validated against the applicable official standards before use in a real compliance engagement.
