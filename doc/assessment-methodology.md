
# Assessment Methodology

## 1. Assessment Approach

This project uses a simulated, evidence-based approach to assess selected ISO 27001:2022 Annex A controls.

The assessment evaluates control implementation, identifies potential gaps, and recommends corrective actions.

## 2. Assessment Process

The assessment will follow these steps:

1. Select 30 ISO 27001:2022 Annex A controls.
2. Determine the applicability of each control.
3. Review simulated evidence against assessment criteria.
4. Record implementation status and identified gaps.
5. Document control applicability in the Statement of Applicability (SoA).
6. Map selected controls to NIST CSF 2.0.
7. Recommend remediation actions and priorities.
8. Prepare a summary of findings.

## 3. Implementation Status

Each control will receive one of the following statuses:

- Implemented: Available evidence supports that the control is implemented.
- Partially Implemented: The control is implemented in part, but deficiencies remain.
- Not Implemented: The assessment scenario indicates that the control has not been implemented.
- Not Verified: Available evidence is insufficient to determine implementation status.

## 4. Evidence Assessment

Evidence will be evaluated for relevance, completeness, and consistency with the control being assessed.

Missing or insufficient evidence will be documented for follow-up rather than automatically treated as proof that a control does not exist.

## 5. Gap Prioritization

Identified gaps will be assigned proposed risk ratings of High, Medium, or Low.

Prioritization will consider potential business impact, likelihood, existing safeguards, and the urgency of remediation.

These ratings are illustrative and form part of the simulated assessment.

## 6. Framework Mapping

Selected ISO 27001:2022 Annex A controls will be mapped to relevant NIST CSF 2.0 outcomes.

Each mapping will include a rationale. The mapping does not imply that the frameworks have identical requirements.

## 7. Limitations

This methodology is designed for a simulated portfolio project. It does not replace a formal ISO 27001 audit or certification assessment.
